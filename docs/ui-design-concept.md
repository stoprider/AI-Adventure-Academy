# UI Design Concept

## Vision
ทำให้เด็กรู้สึกเหมือนกำลังเข้าไปในศูนย์บัญชาการของนักสำรวจเมืองอนาคต มากกว่าการนั่งเรียนบทเรียน AI แบบปกติ

## Visual Direction

- โทนสีหลัก: navy, cyan, orange เพื่อให้สดใสและมีพลัง
- พื้นหลัง: ใช้ gradient และ radial glow เพื่อสื่อถึงโลกอนาคต
- รูปทรง: มุมโค้งใหญ่ ปุ่มใหญ่ กดง่าย
- Typography: หัวข้อชัด หนา อ่านง่าย
- Motion: floating card, glow animation, hover transition

## UX Principles

- เริ่มเล่นได้เร็วที่สุดด้วย guest mode
- หนึ่งหน้าควรมีเป้าหมายชัดเพียงหนึ่งอย่าง
- คำอธิบายใช้ภาษาง่ายและเน้นกำลังใจ
- แสดง feedback ทันทีหลังทำภารกิจ
- ใช้สีและ layout ช่วยบอกลำดับความสำคัญของข้อมูล

## Accessibility

- contrast สูง
- ขนาดปุ่มเหมาะกับการแตะบนมือถือ
- รองรับหน้าจอเล็กด้วย card layout
- ใช้ข้อความแทน icon สำคัญเสมอ
