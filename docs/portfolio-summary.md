# Portfolio Summary

## Project Title
AI Adventure Academy

## One-Line Pitch
A game-based AI learning web app for middle school students that teaches prompting, problem solving, and AI ethics through playful missions.

## Who It Is For

- Students aged 12-15 with no prior AI background
- Teachers who want a classroom-friendly AI activity
- Judges or reviewers looking for a practical educational technology project

## Core Value

- Makes AI feel fun instead of intimidating
- Demonstrates full-stack development with documentation
- Shows educational design, gamification, analytics, and deployment readiness

## Key Deliverables

- Full React frontend with responsive UI
- Node.js + Express backend
- SQLite database with seed data
- Admin dashboard with export
- Guest mode player flow
- Missions, XP, levels, badges, leaderboard, classroom demo
- SRS, SDLC, architecture, API docs, wireframes, deployment guide
- Backend tests for core logic and API smoke flows

## Demo Flow

1. Start in Guest Mode
2. Explore a mission or daily challenge
3. Submit an answer and receive feedback
4. Earn XP, coins, and achievements
5. View progress, leaderboard, and classroom demo

## Why This Project Stands Out

- Blends education and game design
- Uses a realistic full-stack structure
- Includes documentation beyond code
- Ready for portfolio, classroom demo, or further AI API integration
